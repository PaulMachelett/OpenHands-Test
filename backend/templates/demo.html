Flask Backend Demo

Willkommen zur Demo des Flask-Backends mit SQLAlchemy und Mock-Database.

Verfügbare Endpunkte

POST /register

Benutzer registrieren

Beispiel: 
curl -X POST http://localhost:12001/register \
  -H "Content-Type: application/json" \
  -d '{"name": "testuser", "email": "test@example.com", "password": "password123"}'

POST /login

Benutzer anmelden

Beispiel: 
curl -X POST http://localhost:12001/login \
  -H "Content-Type: application/json" \
  -d '{"email": "test@example.com", "password": "password123"}'

GET /notes

Alle Notizen des Benutzers abrufen

Beispiel: 
curl -X GET http://localhost:12001/notes \
  -H "Authorization: Bearer YOUR_SESSION_TOKEN"

POST /notes

Neue Notiz erstellen

Beispiel: 
curl -X POST http://localhost:12001/notes \
  -H "Content-Type: application/json" \
  -H "Authorization: Bearer YOUR_SESSION_TOKEN" \
  -d '{"title": "Meine Notiz", "content": "Das ist der Inhalt meiner Notiz."}'

Demo-Benutzer

  • Benutzer: john@example.com / password123

Test-Suite

Das Backend verfügt über eine umfassende Test-Suite mit pytest:

cd backend && python -m pytest tests/ -v

Architektur

  • Flask: Web-Framework
  • SQLAlchemy: ORM für Datenbankmodelle
  • Mock-Database: In-Memory-Simulation einer SQLite-Datenbank
  • pytest: Test-Framework mit umfassenden Integrationstests
